======================================================================
                  📖 5년 일기장 (웹 버전) 사용 설명서
======================================================================

5년간의 소중한 추억과 일상을 하루 한 페이지로 기록하고 비교할 수 있는
나만의 안전한 감성 일기장 웹 애플리케이션입니다.

----------------------------------------------------------------------
1. 💡 가장 중요한 점: 완벽한 개인정보 보호 및 데이터 보안
----------------------------------------------------------------------
- 본 일기장은 **어떠한 외부 서버나 클라우드로도 데이터를 전송하지 않습니다.**
- 모든 일기 내용은 **사용자 PC의 웹 브라우저 내부(localStorage)**에만 
  암호화된 안전한 형태로 100% 로컬 저장됩니다.
- 개발자를 포함하여 그 누구도 사용자의 일기 내용을 열람하거나 수집할 수 
  없으므로 안심하고 소중한 일상을 기록하세요.


----------------------------------------------------------------------
2. 🚀 로컬 PC에서 실행하는 방법 (새 컴퓨터에서도 원클릭 자동 실행!)
----------------------------------------------------------------------
■ [방법 1] 5년일기시작.bat 또는 바탕화면 바로가기 실행 (가장 추천 ⭐)
  - `5y_Diary` 폴더 안의 [5년일기시작.bat] (또는 바탕화면의 [5년 일기장.bat])을 더블클릭합니다.
  - **새 컴퓨터에서 처음 실행할 때**:
    1) Node.js가 설치되어 있지 않으면 **공식 Node.js를 자동으로 다운로드 및 설치**합니다.
    2) 필요한 일기장 라이브러리(`http-server`)도 자동으로 설치합니다.
    3) 설치 완료 후 자동으로 로컬 서버를 띄우고 브라우저를 실행합니다.
  - **이후 실행할 때**: 1초 만에 바로 일기장이 열립니다.
  - **스마트 자동 탐색**: 폴더를 다른 드라이브나 위치로 옮겨도 스스로 새 위치를 찾아내어 기억합니다.

■ [방법 2] 온라인 웹 주소로 바로 접속
  - 인터넷이 되는 환경이라면 웹 브라우저(크롬, 엣지, 웨일 등)에서 
    아래 주소로 접속하여 언제 어디서나 바로 사용할 수 있습니다:
    👉 https://pitagy.github.io/5y_dairy/

3. 📱 주요 기능 및 사용법
----------------------------------------------------------------------
① 달력 보기 (Calendar View)
   - 상단의 연도/월을 선택하여 원하는 날짜의 카드를 클릭하면 일기를 작성할 수 있습니다.
   - 상단 연도(예: 2026년)를 클릭하면 원하는 연도로 바로 이동할 수 있습니다.
   - [오늘] 버튼을 누르면 오늘 날짜의 달력으로 바로 복귀합니다.

② 5년간 일기 비교 보기 (Multi-Year View)
   - 우측 상단의 [5년간 일기] 버튼을 누르면 특정 날짜의 지난 5년간의 기록을 
     위아래로 한눈에 비교하며 볼 수 있습니다.
   - 기본적으로 [현재 연도 기준 과거 5년]의 기록이 표시됩니다.
   - [최근 3년], [최근 5년], [최근 10년], [전체 기록] 버튼으로 보고 싶은 기간을 
     자유롭게 변경할 수 있습니다.
   - [연도 선택] 드롭다운을 통해 시작 연도와 끝 연도를 원하는 대로 설정할 수 있습니다.
   - 날짜 제목을 누르면 원하는 월/일로 즉시 점프할 수 있습니다.


----------------------------------------------------------------------
4. 🔄 PC 웹버전과 스마트폰(APK/아이폰) 간 데이터 동기화 방법
----------------------------------------------------------------------
서버에 데이터를 보관하지 않으므로, 기기를 바꾸거나 스마트폰과 PC 간에 
일기를 공유하려면 [백업 / 복구] 기능을 사용합니다.

■ PC에서 스마트폰으로 일기 옮기기 (또는 백업하기)
  1. PC 일기장 상단의 [내보내기 (↓ 화살표)] 아이콘을 클릭합니다.
  2. `5y_diary_backup_날짜.json` 백업 파일이 다운로드 폴더에 저장됩니다.
  3. 이 파일을 카카오톡(나에게 보내기), 이메일, 네이버 MYBOX, 구글 드라이브 등으로 
     스마트폰에 보냅니다.
  4. 스마트폰 일기장 앱을 열고 상단의 [불러오기 (↑ 화살표)] 아이콘을 누른 후 
     전송받은 백업 파일을 선택합니다.
  5. 기존 데이터와 안전하게 합쳐지며 모든 일기가 즉시 동기화됩니다!

■ 스마트폰에서 PC로 일기 옮기기
  - 스마트폰 앱에서 [내보내기]를 눌러 다운로드한 백업 파일을 PC로 보낸 후, 
    PC 일기장에서 [불러오기]를 실행하시면 됩니다.

※ 팁: 중요한 일기 기록을 보존하기 위해 한 달에 한 번씩 [내보내기]를 통해 
      백업 파일을 보관해 두시는 것을 권장합니다.
