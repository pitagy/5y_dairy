======================================================================
              📱 5년 일기장 (안드로이드 APK 패키지) 설치 및 사용 가이드
======================================================================

PWABuilder를 통해 생성된 안드로이드 앱 패키지(5년 일기.zip)를 스마트폰에 
설치하고 안전하게 사용하는 방법 안내서입니다.

----------------------------------------------------------------------
1. 💡 가장 중요한 점: 완벽한 데이터 프라이버시 (로컬 100% 저장)
----------------------------------------------------------------------
- 이 일기장 앱은 **어떠한 서버나 외부 데이터베이스로도 일기를 전송하지 않습니다.**
- 사용자가 작성한 모든 일기는 **사용자의 스마트폰 기기 내부(내부 저장소)**에만 
  안전하게 보관됩니다.
- 서버 해킹, 개인정보 유출, 클라우드 오류 등의 걱정 없이 나만의 사적인 기록을 
  안전하게 남기실 수 있습니다.


----------------------------------------------------------------------
2. 📦 다운로드받은 패키지(5년 일기.zip)로 스마트폰에 앱 설치하기
----------------------------------------------------------------------
■ [1단계] 압축 풀기
  1. `C:\Users\pitagy\Downloads\5년 일기.zip` 파일의 압축을 풉니다.
  2. 압축을 풀면 폴더 안에 확장자가 `.apk`로 끝나는 설치 파일이 들어 있습니다.
     (예: `5y-diary.apk`, `app-release.apk` 또는 `assetpacks` 관련 폴더 내부)

■ [2단계] 스마트폰으로 APK 파일 전송하기
  - 카카오톡(나와의 채팅방)으로 `.apk` 파일을 전송하거나,
  - 네이버 MYBOX, 구글 드라이브, 이메일 첨부파일, 또는 PC-스마트폰 USB 연결을 통해 
    스마트폰의 [다운로드] 폴더로 APK 파일을 보냅니다.

■ [3단계] 스마트폰에서 설치 실행
  1. 스마트폰에서 전송받은 `.apk` 파일을 터치하여 실행합니다.
  2. "출처를 알 수 없는 앱" 또는 "보안상의 이유로 이 소스에서 설치할 수 없습니다" 
     라는 안내창이 나타나면 [설정]을 눌러 **[이 출처의 앱 설치 허용]**을 켜줍니다.
     (구글 플레이스토어를 거치지 않고 직접 만든 개인 전용 앱이므로 정상적인 보안 알림입니다.)
  3. [설치] 버튼을 누르면 설치가 완료되며, 홈 화면에 예쁜 5년 일기장 아이콘이 생성됩니다!


----------------------------------------------------------------------
3. ✨ 스마트폰 앱의 편리한 기능: 코드 자동 업데이트
----------------------------------------------------------------------
- 이 앱은 PWA(Progressive Web App) 및 TWA 기술을 기반으로 동작합니다.
- 따라서 이번처럼 **GitHub 저장소의 코드를 수정/업데이트(Push)하면, 스마트폰 앱을 
  새로 삭제하고 다시 깔 필요가 전혀 없습니다!**
- 앱을 완전히 닫았다가 다시 실행하면 자동으로 최신 버전(과거 5년 기본 보기, 
  연도 선택 기능 등)이 스마트폰에 바로 적용됩니다.


----------------------------------------------------------------------
4. 🔄 PC 버전과 스마트폰 앱 간의 데이터 공유 및 백업 방법
----------------------------------------------------------------------
데이터가 중앙 서버가 아닌 각 기기(PC, 스마트폰)에 독립적으로 저장되므로, 
두 기기 간에 일기를 동기화하거나 백업하려면 아래 방법을 사용합니다.

■ 스마트폰 일기를 PC로 옮기기 (또는 백업)
  1. 스마트폰 일기장 앱 상단 메뉴의 **[내보내기 (↓)]** 버튼을 누릅니다.
  2. `5y_diary_backup_날짜.json` 백업 파일이 스마트폰에 다운로드됩니다.
  3. 이 파일을 카카오톡이나 이메일 등으로 PC로 전송합니다.
  4. PC에서 일기장을 열고 **[불러오기 (↑)]** 버튼을 눌러 해당 파일을 선택합니다.
  5. 스마트폰에서 작성한 일기가 PC 일기장에 그대로 합쳐집니다!

■ PC 일기를 스마트폰으로 옮기기
  1. PC 일기장에서 **[내보내기 (↓)]**를 눌러 백업 파일을 다운로드합니다.
  2. 백업 파일을 스마트폰으로 전송합니다.
  3. 스마트폰 일기장 앱에서 **[불러오기 (↑)]**를 눌러 백업 파일을 선택합니다.
  4. PC에서 쓴 일기가 스마트폰 앱에 완벽하게 반영됩니다.


----------------------------------------------------------------------
5. 🍏 아이폰(iOS) 사용 팁
----------------------------------------------------------------------
- 아이폰에서는 복잡한 APK 설치 없이 **Safari(사파리) 브라우저**로 
  `https://pitagy.github.io/5y_dairy/` 에 접속한 뒤,
  하단 [공유 버튼] → **[홈 화면에 추가]**를 누르시면 안드로이드 앱과 
  동일하게 전체화면 독립형 앱으로 바로 사용하실 수 있습니다.
